# desk-speakers
Powered desk speakers, that I can plug straight into my Mac using its barrel jack. They use the Dayton audio ND65-8 2.5" driver, though I imagine any 2.5" driver would work. The amp is a adafruit amp, though again any amp in breakout board form would do. They are printed with very thick walls, and high infill of 80% or higher is recommended.
